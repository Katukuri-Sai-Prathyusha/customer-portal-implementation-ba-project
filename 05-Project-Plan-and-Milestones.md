# 05 - Project Plan & Milestones

## Project

Customer Portal Implementation & Digital Transformation

## 1. Project Delivery Approach

The project follows an Agile delivery approach with iterative development and business validation after each sprint.

## 2. Project Timeline (High-Level)

| Phase | Duration | Owner |
|-------|----------|-------|
| Project Initiation | Week 1 | PM + BA |
| Requirement Gathering | Weeks 1–2 | BA |
| Solution Design | Weeks 3–4 | Product + Development |
| Sprint 1 Development | Weeks 5–6 | Development Team |
| Sprint 2 Development | Weeks 7–8 | Development Team |
| System Testing | Week 9 | QA Team |
| User Acceptance Testing | Week 10 | BA + Business Users |
| Go-Live Preparation | Week 11 | PM + BA + IT |
| Production Go-Live | Week 12 | PM + IT |
| Hypercare Support | Week 13 | Support + BA |

| Milestone | Expected Outcome |
|-----------|------------------|

## 4. Sprint Plan

### Sprint 1

**Goal:** Build customer authentication and support request creation.

**Features**

- Login
- Registration
- Password Reset
- Create Support Request
- Request Categories

### Sprint 2

**Goal:** Build request tracking and notifications.

**Features**

- Request Status
- Request History
- Email Notifications
- Dashboard
- Knowledge Base Search

---

## 5. Project Dependencies

| Dependency | Impact |
|------------|--------|
| CRM Integration | Required for request synchronization |
| Customer Database | Required for authentication |
| Knowledge Base Content | Required before portal launch |
| Email Notification Service | Required for customer communication |
| UAT Environment | Required before business testing |
| Production Infrastructure | Required before deployment |

---

## 6. Critical Path

The project cannot proceed to the next stage until these activities are completed.

1. Project Charter Approval
2. Requirements Sign-Off
3. Solution Design Approval
4. Development Completion
5. System Testing Completion
6. UAT Approval
7. Go-Live Approval

---

## 7. Deliverables by Phase

| Phase | Deliverables |
|-------|--------------|
| Discovery | Business Case, Project Charter, Stakeholder Analysis |
| Analysis | Requirements, User Stories, Acceptance Criteria |
| Design | UI Wireframes, Functional Design |
| Development | Portal Features |
| Testing | Test Cases, Defect Log |
| UAT | Business Sign-Off |
| Deployment | Go-Live Checklist |
| Closure | Lessons Learned, Project Closure Report |

---

## 8. Business Analyst Responsibilities During Project Execution

- Facilitate requirement workshops.
- Prioritize backlog with Product Owner.
- Clarify requirements during development.
- Participate in sprint planning.
- Review sprint demos.
- Coordinate UAT with business users.
- Track requirement completion.
- Support go-live readiness.
